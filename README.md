# Трекер цен с Claude


[![hexlet-check](https://github.com/man-and-code/vibecoding-claudecode-project-388/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/man-and-code/vibecoding-claudecode-project-388/actions)

Соберите на Claude-скиллах трекер цен: он сам следит за товарами и присылает в Telegram только значимые изменения.

Учебный проект Хекслета: https://ru.hexlet.io/programs/vibecoding-claudecode

Ниша проекта — **саке**. Источник данных — интернет-магазин [decanter.ru](https://decanter.ru/): трекер отслеживает 10 выбранных SKU по прямым ссылкам на карточки товаров.

## Стек

- **Claude Code** — среда выполнения: скиллы, sub-agent и весь сценарий прогона запускаются в ней
- **Claude Skills** — `extract-price` и `tracker`: логика проекта описана инструкциями, а не кодом
- **Claude sub-agent на Haiku** — `telegram-summary` формулирует текст сводки
- **Python 3** — `send.py`, только стандартная библиотека (`urllib`, `json`, `os`, `sys`)
- **GitHub / GitHub MCP** — прогоны сохраняются в приватный репозиторий `man-and-code/tracker-data`
- **Telegram Bot API** — метод `sendMessage` для доставки сводки

## Установка

```bash
git clone https://github.com/man-and-code/vibecoding-claudecode-project-388.git
cd vibecoding-claudecode-project-388
```

Отдельная установка зависимостей не нужна: `send.py` использует только стандартную библиотеку Python 3.

Что требуется для полного прогона:

- **Claude Code** с доступом к этому репозиторию — скиллы и sub-agent подхватываются из каталога `.claude/`;
- **GitHub MCP** с доступом на запись в приватный репозиторий `man-and-code/tracker-data` — туда сохраняются прогоны;
- **Telegram-бот** и начатый с ним личный диалог;
- **сетевой доступ** к доменам `decanter.ru` и `api.telegram.org`.

Переменные окружения (читаются только из окружения, файл `.env` проект не использует):

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота, выданный BotFather |
| `TELEGRAM_CHAT_ID` | идентификатор чата, куда отправляется сводка |

Проверить отправку отдельно от трекера:

```bash
python3 send.py "тест"
```

При успехе скрипт печатает `Отправлено.` и завершается с кодом `0`. Если переменные не заданы, текст не передан или Telegram вернул ошибку — выводится понятное сообщение и ненулевой код возврата.

## Использование

Трекер запускается в Claude Code вызовом скилла:

```
/tracker
```

Того же результата достигает обычная просьба в сессии — например, «запусти tracker». Скилл проходит весь сценарий сам: собирает цены, сравнивает с предыдущим прогоном, сохраняет результат и отправляет сводку.

Отдельный скилл `extract-price` можно вызвать для одной карточки товара, если нужно проверить извлечение цены по конкретному URL.

## Как это работает

1. **Обход URL.** `tracker` идёт по зашитому в скилл списку из 10 ссылок на карточки саке.
2. **Извлечение цены.** Для каждого URL вызывается `extract-price` и возвращает `regular_price`, `sale_price`, `has_credit`.
3. **Текущий прогон.** Результаты собираются в одну таблицу — строка на товар.
4. **Сравнение с предыдущим прогоном.** Предыдущий файл `YYYY-MM-DD.json` читается из `tracker-data` через GitHub MCP, записи сопоставляются по URL.
5. **Фильтрация значимых изменений.** Правила значимости берутся из `KNOWLEDGE.md` — он единственный источник истины: порог 1% для цен, появление и исчезновение скидки, любое изменение `has_credit`, новый и пропавший URL.
6. **Два независимых этапа.** Прогон сохраняется в `tracker-data` отдельным файлом `YYYY-MM-DD.json`, а по значимым изменениям sub-agent `telegram-summary` формирует короткую сводку, которую отправляет `send.py`. Сбой одного этапа не отменяет другой. Если значимых изменений нет, в Telegram ничего не уходит.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `.claude/skills/extract-price/SKILL.md` | извлечение цены с одной карточки товара: обычная цена, акционная цена, признак рассрочки |
| `.claude/skills/tracker/SKILL.md` | сценарий прогона: обход URL, таблица, сравнение, сохранение, отправка |
| `.claude/agents/telegram-summary.md` | sub-agent на модели Haiku: превращает готовый diff в текст сводки |
| `KNOWLEDGE.md` | правила значимости изменений между прогонами |
| `send.py` | отправка одного текстового сообщения в Telegram |
| `CLAUDE.md` | контекст проекта для Claude Code: ниша, источник, контракт цены, список SKU |
| `.github/workflows/hexlet-check.yml` | автоматические тесты Хекслета |

Данные прогонов в этом репозитории не хранятся: файлы `YYYY-MM-DD.json` лежат в приватном `man-and-code/tracker-data`.

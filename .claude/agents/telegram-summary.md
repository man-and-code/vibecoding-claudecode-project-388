# telegram-summary

Единственная задача — **сформулировать текст** Telegram-сводки по уже готовому
списку значимых изменений, который передал `tracker`.

## Границы

- Значимость изменений **не определять**: список приходит готовым.
- `KNOWLEDGE.md` не читать, пороги и формулы не применять.
- С `tracker-data` не работать, прогоны не читать и не сохранять.
- `send.py` не вызывать, в Telegram ничего не отправлять, сеть не использовать.
- Файлы не изменять.

Отправкой занимается `tracker`, он же передаёт готовый текст в `send.py`.

## Вход

От `tracker` приходят:

1. дата прогона в формате `YYYY-MM-DD`;
2. список значимых изменений: для каждого — название товара, URL, поле
   (`regular_price`, `sale_price`, `has_credit` или `URL`), значение «было» и
   значение «стало»;
3. правила оформления.

Правила из промпта имеют приоритет. Раздел ниже — тот же формат, зафиксированный
в `.claude/skills/tracker/SKILL.md`; применять его, если в промпте правила не
уточнены.

## Формат сводки

- Первая строка — заголовок с датой прогона и количеством значимых изменений.
- Дальше одна строка на одно значимое изменение, в том же порядке, в каком
  изменения перечислены во входных данных, и строкой ниже — URL товара.

Форма строки:

```
Название товара — поле: было -> стало
URL
```

Пример:

```
Price tracker 2026-09-14: значимых изменений — 3

Iku's Shiro 0,5 л — regular_price: 3500 -> 3780
https://decanter.ru/product/iku-s-shiro-id259675

Ozeki Josen Kinkan 0,72 л — sale_price: null -> 1530
https://decanter.ru/product/ozeki-josen-kinkan-id127358

Akashi Tai Junmai Ginjo Sparkling 0,3 л — has_credit: true -> false
https://decanter.ru/product/akashi-tai-junmai-ginjo-sparkling-id253906
```

Правила оформления текста:

- значения переносить как есть: числа числами, `null` писать словом `null`,
  `has_credit` — `true` / `false`; ничего не пересчитывать, не округлять и не
  переформатировать;
- если название товара не передано, оставить только URL;
- для появившегося URL поле — `URL`, «было» — `нет в прогоне`, «стало» —
  `добавлен`; для пропавшего — наоборот: `был` -> `нет в прогоне`;
- разметку не использовать: обычный текст без Markdown и HTML;
- не использовать двойные кавычки: текст передаётся в `send.py` одним
  аргументом в двойных кавычках;
- ничего не добавлять от себя: ни полной таблицы цен, ни советов, ни
  комментариев о скидках.

## Ответ

Вернуть **только готовый текст сводки**. Без преамбулы, заголовков ответа,
пояснений, извинений и обрамляющих кавычек или блоков кода: весь ответ целиком
уходит в Telegram как есть.
